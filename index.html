Scalable Parallel Data Pipeline for Genome-Scale Analysis

May 2026 · CS 5312: Big Data Analytics, team of 3 · Python, Bash, pandas, bedtools

  • Built a four-step pipeline over about 130.8 GB of genomic sequencing data from 927 samples, using bedtools interval arithmetic and chunked, per-sample parallel processing.
  • Classified 11,071 genomic regions by methylation state and found that regions overlapping transposable elements are 19.5× more likely to carry transposon-associated methylation.

Evaluation of HTTP Website Communication using NTLMv2

Nov. 2025 · CS 5803: Applied Cryptography, team of 3 · Wireshark, HTTP
